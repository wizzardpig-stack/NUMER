# NUMER

A local-first Pythagorean numerology instrument for names, identity patterns, comparison, and symbolic reflection. NUMER is designed as one continuous manuscript surface rather than a conventional dashboard.

## Live

https://wizzardpig-stack.github.io/NUMER/

## What it demonstrates

- Responsive single-page product with custom manuscript-style UI
- Client-side numerology calculations and interactive visual output
- Dedicated responsive breakpoints for tablet and phone layouts
- Mobile web-app metadata, favicon treatment, and touch-friendly forms
- Local-first operation with no account or backend required

## Stack

HTML, CSS, vanilla JavaScript, SVG and local browser state.

## Development approach

Independent product direction, visual system design, iteration, testing, and AI-assisted implementation. The emphasis is on turning a domain-specific concept into a coherent working instrument rather than a generic app shell.

## Release

Current production build: **V12.15**. Promoted from the phone-gate release candidate after automated regression found no reproducible P0 or P1 defects. Remaining hardware/accessibility checks are documented in `qa/REGRESSION_VERDICT_V12_15.md`.
